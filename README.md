# ذكر وحكاية — Zikr Wa Hikaya

تطبيق أندرويد إسلامي: قرآن كريم كامل بالمصحف المصوّر والنص العثماني، تلاوات بأصوات ٢٤٤ قارئًا، مكتبة أذان بأصوات الشيوخ، أذكار الصباح والمساء بصوت الشيخ مشاري العفاسي، رقية شرعية، مواقيت صلاة وتنبيهات أذان، متعقّب صلاة، حاسبة زكاة، أسماء الله الحسنى، وحديث اليوم.

An Islamic Android app: the full Quran (imaged Madina Mushaf + Uthmani text), recitations by 244 reciters, an adhan library, morning & evening adhkar, ruqyah, prayer times with adhan alerts, a prayer tracker, a zakat calculator, the 99 Names, and a daily hadith.
